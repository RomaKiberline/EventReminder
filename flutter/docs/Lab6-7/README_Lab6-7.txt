Лабораторні №6–7. Event Reminder — UI/UX на Flutter.

До пакета включено Word-звіт, PDF для перегляду, карту навігації,
схему компонентів, wireframe та концептуальні макети.

Доказові скриншоти UI з працюючого Android-застосунку ПОКИ НЕ ДОДАНІ.
Не видавайте mockup/wireframe за скриншоти застосунку.
Рекомендовані скриншоти:
  1) Головна з подіями
  2) Календар у режимі «Місяць»
  3) Форма «Нова подія»
  4) Пошук / категорії / налаштування
  5) Широкий екран/desktop, якщо можливий запуск

Код базується на архіві EventReminder_Complete_Flutter_Project_v1_1.zip.
Цей лабораторний комплект НЕ містить нових змін у коді віджетів.
Якщо локальний проект змінювався після v1.1, не перезаписуйте його архівом.

МЕЖІ ВІДПОВІДНОСТІ МЕТОДИЧЦІ:
Вказівки №6-7 конкретно про WEB frontend Vite/Next.js, HTML/CSS і REST API.
Flutter UI з локальною SQLite не є повним еквівалентом цих вимог.
До здачі уточніть у викладача, чи дозволено Android/Flutter як альтернативу.

Перевірка проекту на Windows/Android — на ПК користувача:
  flutter pub get
  flutter analyze
  flutter test
  flutter run -d <device_id>
У цьому середовищі не виконувався flutter build / flutter test.
